## 2. Why N3 wins the first pass

1. **Ships need it today:** inspectors find drifting sensors and wrong test gas; gas carriers are detained more often [G1 to G4].
2. **Same box, same record:** the hardware, signing and one way design are the monitoring bench box; radiation monitors are just another sensor.
3. **Same buyers later:** ports, class and insurers that will judge reactor data first judge gas detector data.
4. **Biggest fleet:** about 1,100 ships able to run on gas fuels in service and 1,000 on order, plus gas carriers [G13 to G17], against 46 ammonia ships.

## 3. What would change the order

| Finding | Effect |
|---|---|
| Recent inspection data show gas detection findings are rare | N3 problem 4 → 3; N3 loses its lead |
| A maker (Consilium, Dräger) or Teledyne launches neutral fixed system health | N3 differentiation 3 → 1 |
| A floating plant developer offers a paid pilot | N4 speed and problem up; nuclear first |
| Part 57 final rule (January 2027) requires independent remote monitoring | N6 up |
